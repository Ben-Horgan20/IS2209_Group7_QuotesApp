## Overview

A Flask web application that aggregates motivational quotes from two sources: the
[API Ninjas Quotes API](https://api-ninjas.com/) (external HTTP API) and a Supabase
PostgreSQL database. The app displays a Quote of the Day, a random quote, and a
category-filtered quote, while persisting all fetched quotes to the database.
